# mAGI logo

The mark: one large node (the conversation) on a bus line, with three agents on taps. The
wordmark is drawn from strokes, so the SVGs need no fonts.

| File | Use |
|---|---|
| `logo-colour.svg` | mark + wordmark, for dark backgrounds |
| `logo-colour-light.svg` | mark + wordmark, for light backgrounds |
| `logo-mono.svg`, `mark-mono.svg`, `wordmark-mono.svg` | one colour (`currentColor`) |
| `mark-colour.svg` | the mark, transparent background |
| `mark-colour-tile.svg`, `favicon-*.png` | the mark on a dark tile: favicons, app icons |

Colours: `#ff8c1a` and `#e5322d` from the `nerv` theme, `#e6e6ea` text, `#0b0b0f` tile.
